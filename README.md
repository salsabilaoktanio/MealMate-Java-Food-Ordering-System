# 🍔 Java Food Ordering System

A Java-based food delivery/ordering system built in NetBeans for my university project using object oriented programming.

## 💻 Key Features
- Roles made in the system: Vendor, Customer, Delivery Runner, Administrator, Manager
- Users can securely log in and log out based on their assigned roles.
- Vendors can manage their menu, handle orders, view order history, track revenue, and read customer reviews.
- Customers can browse menus, place and manage orders, track transactions, leave reviews, file complaints, and reorder past meals.
- Delivery runners can manage delivery tasks, update task statuses, view delivery history, track earnings, and read customer feedback.
- Administrators can register and manage users, top-up customer credit, and generate and send transaction receipts.
- Managers can monitor vendor and runner performance, resolve complaints, and moderate vendor item listings.

## 🖥 GUI Design
The system features a user-friendly GUI built with Java Swing in NetBeans, designed to ensure intuitive navigation for each user role. Each interface is tailored to its respective role.

## 📁 Project Structure
- `src/` — Java source code
- `.txt` files — user, wallet, top-up, and order data

## ⚙️ Tools
- Java (JDK)
- NetBeans IDE

## 📝 How to Run
1. Open the project in NetBeans.
2. Run the main class (`Main.java` or your main JFrame).
